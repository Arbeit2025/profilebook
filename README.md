# profilebook

懐かしのプロフィール帳をブラウザで書けるようにした、プロフィール帳ジェネレーター。

## 機能
- プロフィール帳の定番項目（なまえ／ニックネーム／誕生日／血液型／好きな食べ物／好きな色／好きな音楽・歌手／趣味／特技／将来の夢／今ほしいもの／一言メッセージ）を入力できます
- 「ランダムお題」：24のお題から3つがランダムで出題され、それぞれ自由に答えられます。「お題をシャッフル」ボタンで引き直しもできます
- 入力すると、罫線ノート風のプレビューがその場で更新されます
- 入力内容はブラウザの localStorage に自動保存され、次に開いたときも続きから書けます（サーバーには送信されません）
- 「文章でコピー」ボタンで、プロフィール全体をプレーンテキストとしてコピーできます
- 「全部消す」ボタンで、入力と保存内容をリセットできます（確認ダイアログつき）

## 動かし方
```bash
pip install -r requirements.txt
python app.py
```

## テスト
```bash
pip install pytest
pytest tests/
```
